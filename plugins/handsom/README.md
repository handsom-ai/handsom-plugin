# Handsom

Set up and change a Handsom store from your own agent. Handsom handles a Shopify store's support tickets, and this plugin lets you apply a brand's policies, documents and interview notes to its rules, facts and knowledge.

## Use it

Install the plugin, connect the Handsom connector and sign in. Then give your agent the brand's documents and ask it to apply them to the store. It reads the guide, checks each change, saves it and writes a handover.

## Data

The plugin sends what you ask it to save to your Handsom account through https://api.handsom.ai/mcp. It works as you, on the stores you can reach, and it can't see customer conversations.
